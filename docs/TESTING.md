# 验证与手动验收

## 自动检查

运行 `scripts/test.ps1`：

- 编译真实 WPF 可执行文件。
- 在创建任何媒体窗口和调用桌面 API 之前执行 `--self-test`。
- 检查 605 个屏幕过渡矩形，以及 12 个固定尺寸居中和客户区边框补偿场景。
- 另外检查关键帧边界与插值、负坐标显示器、非16:9目标窗口的最终填满。
- 拒绝 NaN/无穷大数值、零长度淡入、重复时间、空关键帧、空进程过滤、无效窗口尺寸和额外 shell 参数。
- 在项目临时目录内建立隔离 `.lnk`，检查精确匹配、保留图标、递归发现、重复安装、逐字节备份/恢复、用户改动保留、损坏备份拒绝、恢复后不重装、配置关闭。测试明确指定扫描根目录，不触碰实际桌面、开始菜单或任务栏。

自动检查不启动真实客户端、不截图，也不解码视频。打包检查另行验证随附视频的字节哈希。它不能证明媒体解码、DWM 实时缩略图或焦点交接已成功。

## 手动验收

导入 MP4 并校准配置后，使用普通 Windows 桌面进行以下检查：

1. 客户端关闭时启动：动画播放，客户端出现在其后，最终移除播放层。
2. 客户端已运行时启动：接入原窗口，没有第二个客户端窗口。
3. `Esc` 跳过：播放器退出，已有客户端获得焦点。
4. 客户端启动缓慢：视频在 `HoldAt` 停住，客户端出现后继续。
5. 错误或缺失视频：显示明确错误，不留下覆盖窗口。
6. 不同 DPI 和负坐标副屏：验证实际客户区物理像素尺寸与居中位置。
7. DWM 不可用时：验证淡出后仍交给实际客户端。
8. 在衔接完成后输入文字，确认操作的是实际客户端。

快捷方式检查 `scripts/install-start-menu.ps1 -Action Verify` 只验证 `.lnk` 的目标和图标，不证明已经固定到开始菜单。

自动入口替换的验证命令为 `scripts/integrate-entrypoints.ps1 -Action Verify`，结果写入 `.integration/report.json`。它验证文件和元数据，不证明开始菜单/任务栏缓存已经刷新。手动检查首次运行、重新扫描和恢复之后，实际点击各处快捷方式是否走预期入口；确认 `.integration/report.json` 中的失败和扫描限制。测试报告不能代替这些 Windows Shell 验收。
