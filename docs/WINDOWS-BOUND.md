# 0.2.2：窗口绑定与交接画面保留

本版修正统一版的两个具体问题：只按实例选屏但没有匹配窗口区域，以及交接前 Stop/隐藏 MediaElement、清除缩略图导致露出浅色背景。

交付包使用 `TargetDisplay: auto`、`BindToAppWindow: true`。已有 Codex 实例时，播放器覆盖其客户端区域，并跟随目标的位置和尺寸；越出工作区时先将区域约束在可见范围。无实例时先在主屏放置播放器，发现新窗口并验证稳定后，将新窗口客户端对齐播放器区域。绑定会改变越界窗口或冷启动窗口的位置/尺寸，这是本版为实现视觉交接的行为。未修改官方应用文件。

动画结束/跳过时改为 Pause，保留可见视频和实时缩略图；确认同一目标身份、有效性、响应、前台激活，并等待 DWM 提交后再关闭遮盖窗口。缩略图失败时也保留动画直到交接，不提前把播放器淡成透明。等待与错误路径仍有总时限，避免永久最后一帧。

播放器背景改为黑色；视频按比例显示，非 16:9 实例区域可能有黑色边带。目标窗口可见、响应、稳定和 DWM 提交不等于 Codex 内部页面已完成内容渲染；本版不能保证消除官方应用自身的空白加载画面。

测试范围：几何/配置 22 条断言、生命周期/多屏 55 条断言、隔离入口 33 条断言通过；自测 605 个关键帧与 12 个放置案例通过。桌面宿主检查真实实例与动画的客户端位置/尺寸一致、主副屏可见范围及交接时视频保持可见；另用受控发现与启动注入模拟“无窗口后出现窗口”，核对一次启动请求与冷启动对齐，并恢复被用作测试目标的原窗口位置。真正退出所有 Codex 后的冷启动及全程视觉无闪白仍需人工验收。

解压后运行 `DragonCodexBoot/DragonCodexBoot.exe`。请关闭旧的社区启动器，避免单实例锁阻止新启动。日志位于 logs/launcher.log，版本为 0.2.2.0；交接保留日志为 `handoff-cover-retained media-visible=True`，绑定日志为 `bound-to-app-window` / `cold-window-bound-to-player`。已有窗口从一开始就与播放器对齐时，不一定需要再写移动日志。

保留外部 MP4 和配置，媒体是原安装自定义动画的副本。原安装和旧测试包未覆盖。回滚只需停止本测试包并使用旧版本；正式替换安装前应备份原 EXE/配置，保持原 MP4 不变。
